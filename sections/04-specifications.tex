Final feasibility will be assessed through SKY130 transistor-level simulations and review of the RF pad interface.

Voltage conversion gain is defined using the single-ended IF RMS voltage at the selected shared measurement pad relative to the single-ended RF-pad RMS voltage, with the specified input match and high-impedance IF load.
The gain includes the on-chip baluns, mixer core, output interface, and selected shared output path.
