\section{Deliverables}

The project will be open sourced under the Apache-2.0 license, subject to compatibility with incorporated source materials.

The repository will include:

\begin{itemize}
    \item Transistor-level schematics and simulation testbenches

    \item Circuit documentation and design specifications

    \item Standalone layout and Chipalooza harness integration views

    \item DRC/LVS reports and parasitic extraction results

    \item Reproducible scripts for open-source EDA verification

    \item Post-layout simulation summaries

    \item Silicon measurement results following fabrication
\end{itemize}

The design will be developed and verified using the SKY130 open-source PDK, with reproducible verification through tools such as Xschem, ngspice, Magic, and KLayout.
