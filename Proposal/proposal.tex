\section{Overview}
% ==================================================

% 한 줄에는 한 문장 원칙
% Rule 1: SKY130 공정 및 DRC/전압 제한 준수. 900 MHz는 규정이 아닌 설계 목표.
This project proposes the design and implementation of a \textbf{900 MHz low-power active downconversion mixer} using the open-source SkyWater SKY130 CMOS process.
The proposed IP will use a double-balanced Gilbert-cell architecture to translate RF signals around 900 MHz to a low, nonzero intermediate frequency (IF).
It is intended as a reusable building block for wireless receivers, including IoT and other sub-GHz RF communication systems, such as 802.15.4 (Zigbee) and LoRaWAN.

The baseline design will use fixed biasing.
% digitally programmable biasing이 매력적인 스펙인지 검토해서 여기에 코멘트로 남겨줘
% 다른 더 좋은 스펙이 있을 수도 있잖아(e.g. impedance matching, RF/IF signal 대역대 변환)
% 검토: programmable bias는 저전력/선형성 모드 및 실측 후 동작점 조정에 유용하므로
% baseline 검증 후의 선택 기능으로 유지할 가치가 있음. 각 모드의 gain/NF/IIP3/전력을
% 측정해야 하며, 전류 증가가 모든 성능을 동시에 개선한다고 가정하면 안 됨.
% ADL5801은 bias 조절의 활용 사례일 뿐이며 그 SiGe 성능 수치를 SKY130 목표로 전용하지 않음.
% 우선순위: 내부 balun의 균형과 손실/잡음, 50-ohm 입력 정합, LO 구동 범위,
% IF 출력 구동 및 PVT 검증을 먼저 확보. 임피던스 정합은 부가 기능보다 baseline 요구에 가까움.
% RF/IF 가변 범위는 유용하지만 LO 조정만으로 RF matching/balun/IF bandwidth가
% 자동 확장되지 않으므로, 넓은 범위나 가변 정합 기능은 시뮬레이션 전 약속하지 않음.
% Rule 9: 수치 목표는 설계자 선택이며, 확정 후 중간 변경에는 승인 필요.
If time permits, digitally programmable biasing will be added as an optional enhancement to investigate power--performance trade-offs.

\section{Description}
% ==================================================

The mixer will operate according to $f_{\mathrm{IF}}=\left|f_{\mathrm{RF}}-f_{\mathrm{LO}}\right|$.
For example, an RF input at \(900\,\mathrm{MHz}\) and an LO input at \(899\,\mathrm{MHz}\) will produce a desired IF component at \(1\,\mathrm{MHz}\).
The baseline targets low-IF operation over a \(0.5\)--\(5\,\mathrm{MHz}\) characterization range.
Receiver channel bandwidth, anti-alias filtering, and ADC sampling rate must be selected together for the intended application; the mixer specification does not prescribe an ADC sampling rate.

% \begin{equation}
%     f_{\mathrm{IF}}
%     =
%     \left|f_{\mathrm{RF}}-f_{\mathrm{LO}}\right|.
% \end{equation}

% (?) 너무 낮지 않냐? 보통 ADC sampling rate
% 검토: 1 MHz는 ADC sampling rate가 아닌 IF 중심 주파수의 예시임.
% 낮은 IF는 후단의 속도 부담을 줄일 수 있으나, 신호 대역폭과 flicker noise 및
% image 응답을 함께 고려해야 함. 실수 ADC의 일반 Nyquist sampling에서는
% sampling rate가 IF 중심값이 아니라 입력 신호의 최고 주파수의 2배보다 커야 함.
% [상언] 맞는데 그래도 2 MHz이면 너무 낮잖아
% 답변: 2 MS/s는 1 MHz 단일 톤에 대한 이상적 Nyquist 경계일 뿐, 선택한 ADC 사양이 아님.
% 실측/복조 시에는 신호 상단 주파수, anti-alias filter의 transition band와 oversampling
% 여유를 반영한 더 높은 sample rate를 쓸 수 있으며, 빠른 ADC가 낮은 IF를 금지하지 않음.
% 반대로 IF를 수십 MHz로 올리려면 IF load/buffer의 대역폭, 잡음, 전력 목표를 다시 검증해야 함.
% 따라서 특정 ADC/변조 대역폭이 정해지지 않은 현재는 기존 low-IF 목표를 유지함.
% 0.5--5 MHz는 우선 단일/두 톤 특성평가 범위이며, 특정 무선 표준의 전체 대역폭 보장을 뜻하지 않음.

It will consist of the following subcircuits:

\begin{enumerate}
    \item \textbf{RF Input Balun and Matching Interface:}
    Converts the single-ended RF input into a differential signal on chip and provides the input matching interface.
    Its noise, loss, and amplitude and phase balance will be included in the mixer characterization.

    \item \textbf{RF Transconductance Stage:}
    Converts the incoming RF voltage into a differential current for frequency conversion.

    \item \textbf{Gilbert-Cell Switching Core:}
    Performs frequency translation using a differential LO switching quad.

    \item \textbf{LO Input Balun and Buffer:}
    Accepts a single-ended, externally generated LO signal and generates the differential LO drive on chip using a balun and buffer.
    The required input drive, internal voltage swing, and amplitude and phase balance will be characterized.
    % 실험에서 LO signal을 마음대로 외부 신호로 가정해도 되는지 확인
    % 검토: Rule 6.5/6.6은 측정 계획과 장비 목록을 요구하며 on-chip LO를 의무화하지 않음.
    % 따라서 외부 signal generator를 LO source로 쓰는 측정 계획은 가능하나,
    % 주파수/입력 전력/임피던스/위상잡음 조건을 명시하고 Rule 1/10의 전압 제한을 지켜야 함.
    % 이는 실제 보드에서의 발진기 설계나 사용 가능한 측정 장비가 이미 확보되었다는 뜻은 아님.
    % [상언] 이거 그럼 누가 검증을 하는 것임? 공용 패드 어쩌고 하는 걸로 봐서는 주최 측에서 검증하겠다고 하는 것 아님?
    % 답변: 참가 팀이 설계 검증/실측 계획과 결과를 책임지며, 장비를 가진 다른 팀과 협력 가능.
    % Rule 6.5/6.6은 측정 계획/장비 목록, Rule 16/19는 sign-off/PVT 결과,
    % Rule 20은 참가자의 wrapper 배선, Rule 26은 실측/특성평가/결과 공개를 요구함.
    % harness는 전원/제어/패드 접근을 제공하며 RF/LO 발생이나 NF/IIP3 측정 대행을 뜻하지 않음.
    % FAQ에는 칩 실장 보드와 test board를 설계자에게 보내고 타 팀의 측정 협력을 기대하는
    % 계획이 있으나, Challenge #4의 지급 수량/확정 지원 범위를 보장하는 문구는 아님.

    \item \textbf{IF Load and Output Interface:}
    Converts the downconverted current into an IF voltage suitable for measurement or connection to a subsequent analog stage.

    \item \textbf{Bias Circuitry:}
    Derives local bias currents and voltages from the harness reference resources using current mirrors and local bias networks.
    It sets the mixer tail current, the RF and LO input common-mode levels, and the output-buffer operating point.
    Supply decoupling and bias filtering will be included, with startup circuitry provided if required by the selected bias topology.
    % 여기에 필요한 것들 나열. pull/push stage 같은 것임? 그냥 직류 bias인데 직류 전압기 연결하면 되지 왜 따로 회로가 필요함?
    % 검토: bias circuitry는 DC 동작점 설정/분배 회로이며 push-pull 출력단 자체를 뜻하지 않음.
    % 외부 DC 전압으로 초기 시험은 가능하지만 VGS 고정만으로는 PVT에 따른 ID/gm 변화가 억제되지 않음.
    % [상언] 그럼 current mirror를 통해서 동작점을 설정하는 회로가 필요한 것이네?
    % 답변: 맞음. reference current를 mirror 비율로 복사/스케일하여 tail current와
    % balun/buffer bias를 분배하고, 필요한 DC gate/common-mode 전압을 local network로 생성함.
    % mirror 자체가 정확한 절대 전류 기준을 만드는 것은 아니므로 IREF 및 compliance/headroom 확인 필요.
    % Rule 7.2/7.3의 기준 전압 및 최대 두 기준 전류를 받아 내부 current mirror로 필요한
    % 여러 분기 전류를 만들면 각 bias node에 별도 핀을 쓰지 않고 동작점을 설정할 수 있음.
    % 기준 전류가 있다고 PVT 무관한 gm/NF/linearity까지 보장되는 것은 아니므로 별도 검증 필요.
\end{enumerate}

Input impedance matching will be considered for compatibility with standard \(50\,\Omega\) RF measurement equipment.
The matching network will be designed and characterized together with the input circuitry and relevant pad parasitics.

The on-chip RF and LO baluns will generate the differential signals required by the Gilbert-cell core.
Each external RF and LO input therefore requires one signal pad, while the internal mixer core is driven differentially.

\textbf{Pad requirements:}
% Rule 21: slot별 전용 패드 및 pad library 선택. Rule 22: 고주파용 공유 버스 사용에 주의.
\texttt{RF\_IN} and \texttt{LO\_IN} require dedicated connections suitable for \(900\,\mathrm{MHz}\) signaling.
\texttt{IF\_OUT} also requests a dedicated pad to simplify independent characterization.
The shared analog bus is a possible alternative for the buffered IF output, subject to verification of its bandwidth, gain error, and distortion over the target IF range.
This verification must include switch resistance, bus and pad capacitance, package parasitics, and output-buffer impedance.
The baseline retains the dedicated IF pad until the shared path is demonstrated to meet the measurement requirements.
The final pad arrangement and compatibility with the SKY130 pad library will be confirmed during proposal and schematic review.

The baseline circuit will target a nominal \(1.8\,\mathrm{V}\) core supply, with input and output protection compatible with the harness pad interface.
The harness provides \(1.8\,\mathrm{V}\) digital and \(3.3\,\mathrm{V}\) analog supplies; the final supply connection and protection scheme for the \(1.8\,\mathrm{V}\) mixer will be confirmed during integration review.

% 답변: Rule 7.1에 1.8 V digital/3.3 V analog가 명시됨. 1.8 V analog core가 의무라는 뜻은 아님.

% 따라서 1.8 V는 현재 core 설계 선택이며, 실제 전원 도메인 연결/보호 방식을 확인해야 함.
External RF and LO signal generators will be used for characterization; an on-chip PLL or LO frequency synthesizer is outside the scope of this proposal.

Voltage conversion gain is defined using the single-ended IF RMS voltage relative to the single-ended RF-pad RMS voltage, with the specified input match and high-impedance IF load.
The gain includes the on-chip baluns, mixer core, and output interface.
Specifications will be evaluated under clearly defined RF input power, LO drive, load impedance, supply voltage, and temperature conditions.
Transistor operating voltages and RF input levels will remain within the applicable PDK and pad absolute limits.

The design will be characterized across process, voltage, and temperature corners, including post-layout extracted parasitics.
The acceptance limits and simulation methods will be finalized during schematic review with the challenge organizers.

\section{Verification and Measurement Plan}
% ==================================================
% [상언] https://wiki.hivemakerspace.com/explore/electronics-benchtop/에서 보고 장비 사용 가능한 거 다 써줘

% Rule 6.5: 실측 검증 계획. 장비 목록과 CV는 Rule 6.6/6.7에 따라 별도 제출.
% Rule 13: open-source EDA로 성능 검증 가능해야 함. Rule 16: 재현 가능한 plot/summary와 sign-off 결과.
\subsection{Pre-Layout Verification}

\begin{itemize}
    \item Verify DC operating points and device operating regions.

    \item Evaluate conversion gain across RF frequency, LO drive, and bias conditions.

    \item Verify the on-chip RF and LO balun amplitude and phase balance across operating conditions.
    Include their noise and distortion contributions and all interface and bias circuitry in the measured gain, noise figure, and total DC power.

    \item Characterize RF input impedance and \(S_{11}\).

    \item Evaluate linearity using two-tone RF tests and estimate IIP3.

    \item Evaluate LO-to-RF feedthrough and port isolation.

    \item Analyze noise performance and power consumption.

    \item Perform process, voltage, temperature, and mismatch sensitivity analyses.
\end{itemize}


\subsection{Physical Design and Post-Layout Verification}

% Rule 1: 공정 DRC/전압 한계 준수. Rule 16: 최종 DRC/LVS sign-off 결과 보존.
% Rule 19: post-layout commercial PVT 검증 요구, 온도 상한 110 degC까지의 spec도 허용.
% 정확한 온도 하한/상한과 process corner 목록은 schematic review 때 확정할 설계 항목.
The mixer will be laid out using the SKY130 PDK, with attention to differential symmetry, device matching, parasitic coupling, and RF signal routing.

Verification will include:

\begin{itemize}
    \item Design Rule Check (DRC)

    \item Layout Versus Schematic (LVS)

    \item Parasitic extraction (PEX)

    \item Post-layout conversion gain, linearity, isolation, and power simulations

    \item PVT verification using reproducible open-source workflows
\end{itemize}


\subsection{Silicon Characterization}

The design team will carry out silicon characterization, with collaborative measurements where equipment access requires them.
The harness provides power, control, and signal access to the IP block; characterization uses external stimulus and measurement equipment.
The separate equipment attachment identifies the available facility inventory, proposed uses, and capabilities that still require confirmation.
Following fabrication, RF and LO signals will be applied through the dedicated test pads.

The IF output will be measured using an oscilloscope and signal analyzer, as appropriate, to characterize conversion gain, operating frequency range, and linearity.
Any connection to a \(50\,\Omega\) analyzer input will use a characterized buffer or loading correction consistent with the high-impedance IF specification.

A two-tone RF measurement will be used to determine third-order intermodulation performance.
Input matching and LO leakage will be characterized using RF measurement equipment where available.

Noise figure will be characterized using a calibrated noise source or an equivalent calibrated method, with receiver noise, image-band response, and test-fixture and interface losses accounted for.

Measurements will be compared with pre-layout and post-layout simulation results, and any discrepancies will be documented.

\section{Optional Enhancement: Programmable Bias}
% ==================================================

% Rule 7.4: 최대 24 digital control inputs 중 일부를 사용할 수 있음(실제 할당은 확인).
If the baseline mixer meets its target specifications and the design schedule permits, programmable bias circuitry will be incorporated.

\begin{samepage}
This enhancement will allow selection among several operating bias points to investigate trade-offs between:

\begin{itemize}
    \item Conversion gain
    \item Noise figure
    \item Third-order linearity
    \item DC power consumption
\end{itemize}
\end{samepage}

The implementation may use a digitally controlled current mirror or a switchable bias network.

\textbf{Programmable bias is not required for successful operation or verification of the baseline mixer.} The fixed-bias mixer will remain a standalone, reusable IP block.

\section{Contribution}
% ==================================================

The project aims to provide an accessible, reusable, and silicon-characterized 900 MHz analog mixer IP in SKY130 CMOS.
While the Gilbert-cell topology is well established, an open-source implementation with reproducible verification and measured RF performance would provide a practical building block for educational, research, and open-source wireless SoC development.

The optional programmable-bias extension may further demonstrate how conversion gain, linearity, noise, and power consumption vary with operating conditions, helping future designers select appropriate configurations for their applications.
